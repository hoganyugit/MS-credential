### S1 type=single kp="Planning & managing Azure AI solutions" sk=A3.3
You have an Azure AI Search service that contains an indexer named indexer1. indexer1 ingests product sheets from Azure Blob Storage into an index that a Microsoft Foundry agent uses for grounding.

The portal shows that the most recent runs of indexer1 completed with a status of Success. However, users report that several recently uploaded product sheets are never returned by the agent.

What should you do?

- *A. Call Get Indexer Status and review the errors and warnings of the entries in the execution history.
- B. Query the AzureActivity table for Get Admin Key operations on the search service.
- C. Create a metric alert on the Search Latency metric of the search service.
- D. Instrument the client application to log search events to Application Insights.

> why: Indexer 的一次运行即使有个别文档出错，只要错误数低于 Max failed items 仍显示 Success；Get Indexer Status 返回最近 50 次运行的 executionHistory，其中每次运行的 errors、warnings、itemsProcessed、itemsFailed 能定位失败文档及原因。Activity log 只记录 Get Admin Key 等控制平面事件，Search Latency 是查询性能指标，Application Insights 事件只反映客户端查询行为，都不能解释摄取缺失。
