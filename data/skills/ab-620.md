# A. Plan and configure agent solutions (30–35%)

## A1. Plan an agent solution
- A1.1 Plan integration with enterprise systems | 规划与企业系统的集成方式（连接器、自定义连接器、REST API、MCP、Fabric、Foundry）
  - learn: https://learn.microsoft.com/en-us/microsoft-copilot-studio/guidance/integrations
  - learn: https://learn.microsoft.com/en-us/microsoft-copilot-studio/knowledge-graph-vs-power-platform-connectors
  - learn: https://learn.microsoft.com/en-us/microsoft-copilot-studio/add-tools-custom-agent
- A1.2 Plan identity strategy | 规划身份策略：匿名、Authenticate with Microsoft、手动 OAuth；用户身份还是作者身份访问数据
  - learn: https://learn.microsoft.com/en-us/microsoft-copilot-studio/configuration-end-user-authentication
  - learn: https://learn.microsoft.com/en-us/microsoft-copilot-studio/configuration-authentication-azure-ad
  - learn: https://learn.microsoft.com/en-us/microsoft-copilot-studio/configure-enduser-authentication
- A1.3 Plan channels and deployment | 规划渠道与部署：Teams、Microsoft 365 Copilot、网站、自定义渠道（Direct Line）、电话
  - learn: https://learn.microsoft.com/en-us/microsoft-copilot-studio/publication-fundamentals-publish-channels
  - learn: https://learn.microsoft.com/en-us/microsoft-copilot-studio/publication-add-bot-to-microsoft-teams
  - learn: https://learn.microsoft.com/en-us/microsoft-copilot-studio/publication-connect-bot-to-custom-application
- A1.4 Plan responsible AI strategy | 规划负责任 AI 策略：内容审核、prompt modifications、免责声明、对抗测试
  - learn: https://learn.microsoft.com/en-us/microsoft-copilot-studio/faqs-generative-answers
  - learn: https://learn.microsoft.com/en-us/microsoft-copilot-studio/knowledge-copilot-studio
  - learn: https://learn.microsoft.com/en-us/microsoft-copilot-studio/guidance/responsible-ai
- A1.5 Evaluate security and governance considerations | 评估安全与治理：DLP 策略、Purview、环境、PPAC 管控、共享与权限
  - learn: https://learn.microsoft.com/en-us/microsoft-copilot-studio/admin-data-loss-prevention
  - learn: https://learn.microsoft.com/en-us/microsoft-copilot-studio/security-and-governance
  - learn: https://learn.microsoft.com/en-us/microsoft-copilot-studio/admin-logging-copilot-studio
- A1.6 Plan reuseable agent components | 规划可复用的组件：agent flow、prompt、连接器、子 agent、解决方案
  - learn: https://learn.microsoft.com/en-us/microsoft-copilot-studio/authoring-export-import-copilot-components
  - learn: https://learn.microsoft.com/en-us/microsoft-copilot-studio/library-add-actions
  - learn: https://learn.microsoft.com/en-us/microsoft-copilot-studio/guidance/alm
- A1.7 Design agents for internal or external audiences | 为内部或外部用户设计 agent：认证、渠道、数据暴露面的差异
  - learn: https://learn.microsoft.com/en-us/microsoft-copilot-studio/configuration-end-user-authentication
  - learn: https://learn.microsoft.com/en-us/microsoft-copilot-studio/publication-connect-bot-to-web-channels
  - learn: https://learn.microsoft.com/en-us/microsoft-copilot-studio/admin-share-bots

  - learn: https://learn.microsoft.com/en-us/microsoft-copilot-studio/authoring-system-topics
